## 🚀 About

A robust, fully functional e-commerce application built with **Flutter**, designed for both iOS and Android platforms. This project demonstrates a production-ready architecture using **MVVM (Model-View-ViewModel)** and **Cubit** for efficient state management. It features secure **RESTful API** integration for handling user authentication and product data, ensuring a scalable and responsive user experience.

This tailored solution highlights best practices in mobile development, offering a clean codebase and a modern, high-performance user interface.

## ✨ Key Features

### 🔐 Authentication & User Experience
- **Secure Authentication:** Complete flow for Sign-in, Sign-up, Password Reset, and Log-out.
- **Profile Management:** Users can easily update personal details such as Name and Phone number.

### 📦 Product Discovery
- **Smart Browsing:** Explore products seamlessly across various categories.
- **Product Search:** (In Development) Advanced search capabilities to find items instantly.
- **Optimized Performance:** Implements image caching for lightning-fast load times.

### 🛒 Shopping Engine
- **Dynamic Cart:** Specific management of shopping cart items.
- **Order Processing:** Streamlined checkout with real-time database synchronization.

### 🎨 User Interface
- **Modern Design:** Features animated buttons, custom alert messages, and intuitive navigation.
- **Responsive Layouts:** Polished UI elements that adapt to different screen sizes.
